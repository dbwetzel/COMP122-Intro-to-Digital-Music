# Web App #3 - Synthesizer Preset
*Create a unique synthesizer timbre*

**Objective:** Create (at least) two distinct synth presets; give them descriptive names

## Step 1: Create presets

1. Create two new synth patches using my synth patch editor
 - Open the web app at: https://editor.p5js.org/dbwetzel/full/ry4ZOP325
 - Change the name of the default patch to something more interesting than "default patch"
 - Click the "New Patch" button to create a second patch
 - Change the name of the second patch like you did with the first one (make it something different)
2. Make changes to the parameters for each synth patch/preset
Use the patch selector dropdown menu to switch from one patch to the other
 - If you update the name field of your patch, you should see the change reflected in the menu choices
 - Experiment with different oscillator types
 - Experiment with am & fm modulation
 - Experiment with different oscillator settings
 - Dropdown menus are provided for parameters that require specific choices (waveform types, envelope curves, etc.)
 - Number boxes are provided for parameters that allow you to  freely specify a numerical value.
3. Try out your synth after making an update. There are some pre-loaded sequences that will play with the synth patch you have specified, plus you can use the virtual keyboard. Click the keyboard to activate it.

Read up a little on the concepts of **"harmonicity"** and **"modulation index"** in AM and FM Synthesis (online tutorials). 

You can also make changes to overall **volume** (in dB; 0 is full volume) and **detune amount** (in cents).

## Step 2: Download your patch library as a JSON file

1. At the top-right of the virtual keyboard is a "Download Library" button
2. Press the button to download your current patch library as displayed in the text box (JSON) 
 - The app will create a .zip archive file "synthLibrary.zip." This file will most likely end up in your downloads folder
3. Locate the .zip file and "uncompress it"
 - On Mac, double-click the file to automatically uncompress it. This may have already happened if you downloaded using Safari
 - On Windows, right click on the file and choose "Extract All"
4. Once uncompressed, you should have a folder called "JSON"
 - Inside that folder is a file called "synths.json"

## Step 3: Add your synth library to your own copy of the Synth (on editor.p5js.org)

1. **Open the editor** version of the Web App template: https://editor.p5js.org/dbwetzel/sketches/ry4ZOP325
2. Make sure you are **logged in** to the P5 editor
3. Make a copy of the Synth App in your own account
 - **File -> Duplicate** (you must be logged in first)
4. Upload your "synths.json" file to the "JSON" directory 
 - Look for the "Sketch Files" panel on the left
 - Find the empty folder called "JSON"
 - Use the triangle menu arrow to select "Upload File"
 - Find the synths.json file you created in the steps above (drag & drop or file selector from your downloads)
5. Press the "Run Sketch" play button
 - You should see your own synth presets in the menu
6. Try playing it from the keyboard. Also try the "Jump A" and "Jump B" buttons with your different patches
7. If you want to add more to your library, click "new patch" and create something. 
 - Delete the "synths.json" file from the "JSON" directory in your "Sketch Files"
 - Download your new library as in Step 2 above.
 - Upload the new library file again and run the sketch to see the changes.
