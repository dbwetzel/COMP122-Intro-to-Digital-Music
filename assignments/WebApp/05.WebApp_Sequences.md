# Webb App #5 - Note Sequences
*Design and encode short linear sequences for asynchronous playback*

## Step 1 - Create Short Note Sequences
In this project, you will compose or arrange a set of short musical note sequences. They may be primarily melodic, but they can also be harmonic in nature (chord progressions). The player app can then play these sequences as stand-alone musical objects (asynchronous interactive playback). They will play in time with the Transport's metrical grid, so that beats, sequences can play along together or canonically. This concept is used in the <a href="http://lute.luc.edu/InC" target="_blank">"Play-Along" web app for Terry Riley's In C.</a>

1. **Open** this link:
  - <a href="https://editor.p5js.org/dbwetzel/full/6EPkyiU5a" target="_blank">https://editor.p5js.org/dbwetzel/full/6EPkyiU5a</a>

  ... to compose your short sequences and format your JSON data.

2. Click **"New Sequence"** to create your first short sequence (you must create at least two). Each sequence object has a pre-defined structure:
 - **"name"**: for convenience. Label it with something meaningful
 - **"loop"** : the total length of the sequence before it loops. If the loop length is longer than the sequence, there will be silence until the loop repeats. You can edit this in your final JSON file if you want it to behave differently. 
3. **Add Notes** to the Sequence: Shift-click on the "piano roll" grid to add a note. Click on a note to edit. Shift-click an existing note to delete.
 - Each sequence can have any number of **note objects**, each with the following properties:
  - **"time"** : the start time of the note relative to the launch time of the sequence (not the absolute Transport time). In the example below, time is given in "measures:beats:sixteenths.ticks" format. All start at zero (0), e.g.:
    - **Measure:** whole number, 0 or greater
    - **Beat:** whole number, 0-3 defines which quarter note to play on within the measure
    - **16th:** whole number, 0-3 defines the 16th-note offset from the downbeat to play on
    - **"ticks"** allows for a fractional offset from the 16th note subdivision. It is a decimal fraction of a sixteenth note.
    - **Examples:**
      - "0 : 0 : 0.0" : first measure, first beat, first sixteenth note, or the very beginning of the sequence
      - "0 : 1 : 2.0" : the off-beat of the second beat of the first measure (alternatively, 0 measures from the beginning, 1 beat after the bar line, and two more 16th after the beat).
      - (optional) Make chords: If two notes have the same time values or their durations cause them to overlap, they will sound together as a "chord". You can use this as a creative opportunity to construct chord sequences or contrapuntal sequences.
  - **"pitch"**: the note to play. The example below gives pitch in "scientific notation" with the note letter name and octave (middle C is "C4"). In the editor you can change the pitch of a selected note using the dropdown menu
  - **"dur"** : the duration of the note (how long to hold it).
    - Here's a basic key for understanding Tone.js Time notation: <a href = "https://github.com/Tonejs/Tone.js/wiki/Time" target="_blank">https://github.com/Tonejs/Tone.js/wiki/Time</a>
 - **"vel"** : velocity value (0 - 1) determines the attack volume of the note (not implemented yet, but possibly soon). Default value is 1 (full volume).
 - If you select a note in the "piano roll" editor and make changes to it in the "editor" box, click "apply" to see and play back the changes in your sequence.
4. **Save** the contents of the sequence editor to your library ("Save to Library")

### Note:
 - You will see **player interfaces** under **"Sequence Players."** This is the same interface (well, almost) as you see in the "In C Play-Along" app.
 - Your **JSON data** should also update with your new sequence each time you save it.

5. Create at least **one more sequence.** Use the **"New Sequence"** button to create a new sequence. Give it a name, add some notes, adjust the loop length, and save it to the library.

## Step 2 - Save Your Work
1. **Download** your JSON data ("sequences.json") from the editor.
2. Make your own copy of the sequencer app
 - **Log in** to editor.p5js.org
 - Open the sequencer app: <a href="https://editor.p5js.org/dbwetzel/sketches/6EPkyiU5a" target="_blank"> https://editor.p5js.org/dbwetzel/sketches/6EPkyiU5a</a>
 - Make a copy: **File->Duplicate**
4. **Upload** your .json file
 - Open the **"Sketch Files"** pane on the left ('>')
 - Find the **folder** called **"JSON"**
 - Use the triangle **dropdown** on the right of the **JSON folder** name to **"Upload file"**
 - **Add** your "sequences.json" file to the project
5. **Run** the sketch (triangle "play" button) to see your changes
 - **Scroll down** to see if your sequences are loaded. 
 - Select one in the menu to **load it** in the note editor.
 - **Does it work?** Go on to step 3 ...
